# USH Serenity Spa Dashboard

Modern, multilingual (English / العربية) multi-branch spa center management dashboard built with Next.js 16, Redux Toolkit, Tailwind CSS, and Lucide icons.

## Features

- **Dashboard Overview**: Key metrics (earnings, appointments, customer count, average ticket value), real-time daily status (pending, confirmed, completed, cancelled), 14-day earnings trend area chart, service category split pie chart, weekly overview bar chart, and live upcoming appointments.
- **Appointments Management**: Interactive calendar and table list views, branch filter, status filter, slot booking grid (30min & 60min intervals), appointment details viewer, and booking creation modal.
- **Branch Management**: Overview of Serenity Spa Center branches across Riyadh, Jeddah, and Khobar with real-time occupancy, staff counts, monthly bookings, and revenue.
- **Service Catalog**: Categorized services (Massage, Facial, Body, Nails, Wellness) with duration, pricing in SAR, and booking analytics.
- **Customer Intelligence**: Customer profiles, spending rankings, visit history, and direct contact details.
- **Performance Reports**: Daily, weekly, and monthly KPI breakdown, revenue charts, hourly distribution, top performing services, and top customers.
- **Multilingual & Theming**: Full support for English (LTR) and Arabic (العربية - RTL), plus Light and Dark mode.
- **Rich Demo Data Mode**: Pre-populated with realistic Saudi spa branches, treatments, therapists, customers, and dynamically generated appointments spanning past history, today's schedule, and upcoming bookings.

## Getting Started

```bash
# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build
```
